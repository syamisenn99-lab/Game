# Game

ゲームの試作を、それぞれ独立した Godot プロジェクト（Godot 4.6.3）として置いている。遊ぶときは、各フォルダの `project.godot` を Godot で開く。

| フォルダ | ゲーム |
|---|---|
| [armchair_adventurer/](armchair_adventurer/README.md) | 安楽椅子冒険者（仮題）: 家から出られない主人公が、「声だけ」でつながる冒険者をノートと照合しながらナビゲートする、情報照合サスペンス |
| [misu/](misu/README.md) | 御簾の向こうの御方（試作）: 御簾の奥の「御方」として、扇を開くか閉じるかだけで沙汰を下す。女房の解釈のクセを通してしか、意思は届かない |
