# 御簾の向こうの御方（試作）

平安風の架空の宮廷。プレイヤーは御簾の奥の「御方」で、操作は**扇を開くか閉じるかだけ**。
陳情を聞いて扇を動かすと、取り次ぎの女房がそれを読み取って沙汰を宣言する。女房にはそれぞれ一貫した「解釈のクセ」がある。

確かめたいこと:
1. 正しく判断したのに女房のクセで結果がずれたとき、「理不尽」ではなく「悔しい」と感じられるか
2. 女房のクセを読んで扇を動かし、狙いどおりに伝わったときに手応えがあるか

## 動かし方（Godot 4.6.3 / GDScript）

1. Godot 4.6.3 でこのフォルダ（`misu/project.godot`）を開く
2. F5 で実行（メインシーン: `scenes/main.tscn`）

入力は1つだけ: **スペースキー / マウス左クリック / 画面タップ**（どれも同じ）。押すたびに扇が「開く ⇄ 閉じる」。
文章は扇を動かすと進む（文字送りの途中なら、まず全文を出す）。タイトルやまとめでは「開く＝決定」「閉じる＝構え直し（戻る）」。

画面は縦横どちらでも動く（縦長なら御簾が上、横長なら御簾が左）。基準は 720×720 で、`canvas_items` + `expand` で伸ばすので、720×1280 の縦持ちでも 1280×720 でも短い辺が 720 になる。

## 遊びの流れ

序 → 陳情 ×8（女房3人が交代で取り次ぐ）→ まとめ。各陳情は:

1. 陳情者と証人の話を聞く（はじめての女房なら、名乗りと「噂」＝クセのヒント）
2. **御沙汰の刻**: 扇を閉じた構えから香が燃え尽きるまで（既定 6 秒）の開閉を記録し、所作を読み取る

   | 所作 | 判定 | 宮中の作法での意味 |
   |---|---|---|
   | 閉じたまま | 一度も動かさない | 退ける |
   | 開いたまま | 開いて終わる（1回か3回） | 聞き届ける |
   | 開いて、閉じる | 2回 | 差し戻す |
   | 幾度も開け閉め | 4回以上 | 厳罰 |

   あわせて「ためらい（最初に動くまで 2 秒以上）」「ぴしゃり（開いてから 0.5 秒以内に閉じる）」「長く保つ（最後に開いてから 4.5 秒以上）」も見る。
3. 女房が自分のクセで読み、沙汰を宣言 → その後
4. **振り返り**: 御方の扇・作法どおりの読み・女房の読み（と心の内）・ふさわしい沙汰を並べる。作法どおりの読みを「御方の意図」とみなして5つに分ける
   - 思いどおりに伝わった／女房のクセを読んで通した（体験2）／正しいお心は伝わらなかった（体験1）／御方のお心がずれていた／両方ずれた
5. 女房帖（画面下）に、そのとき見えたクセが書き加えられ、次にその女房が来たときに読める
6. 「伝わらなかった」ときは気持ちをたずねる（扇を開く＝悔しい／待つ＝理不尽）

まとめの内容は `user://playtest_log.json` に毎回追記される（扇を動かした時刻・所作・宣言・分類・気持ち・そのときのしきい値）。試遊の振り返りに使う。

## 女房とクセ（`data/nyobo.json`）

| 女房 | クセ |
|---|---|
| 小萩（若い女房） | 気が早い。すぐに開いて閉じると、開いた瞬間に「聞き届ける」と言ってしまう。ためらってから開閉すれば最後まで見る |
| 常盤（古参の女房） | 高貴の方は退けられず罰せられない（閉じたまま・幾度も → 差し戻す。ぴしゃりと閉じたときだけ退ける）。下々への情けは、早く開いて長く保たないと「差し戻す」 |
| 夕霧（情け深い女房） | 幾度も開け閉めすると「お心の痛み」と読んで聞き届ける。ぴしゃりと閉じると厳罰 |

## 調整のしかた（コードを触らない）

| ファイル | 中身 |
|---|---|
| `data/config.json` | 入力判定と演出のしきい値（御沙汰の刻の長さ、ためらい・ぴしゃり・長く保つの秒数、幾度もの回数、連打よけ、文字送りの速さ、気持ちの質問の有無など） |
| `data/court.json` | 沙汰の名前、作法（所作 → 標準の沙汰）、所作の説明文、身分の名前 |
| `data/nyobo.json` | 女房（名乗り・噂・解釈の規則）。規則は上から順に調べ、`when` がすべて合った最初の規則で決まる。書き方はファイル先頭の `_説明` |
| `data/cases.json` | 陳情（取り次ぐ女房、身分、訴えの台詞、ふさわしい沙汰、4つの沙汰それぞれのお達しとその後）。並び順が出る順 |
| `data/text.json` | 画面の文言（序、見出し、振り返りの書式など） |

データの食い違い（足りない沙汰、いない女房など）は起動時にエラーとして出る。テストでも確かめる。

## フォント

日本語は同梱の Noto Serif JP（`assets/fonts/NotoSerifJP-Regular.otf`、SIL Open Font License 1.1、`assets/fonts/OFL.txt`）で出す。
念のため、OS の明朝・ゴシック（SystemFont）にもフォールバックする。

## エクスポートするとき

- JSON はリソースではないので、エクスポート設定の「リソース以外のファイルを含める」に `data/*.json` を足す
- 日本語の改行を正しくするため、`internationalization/locale/include_text_server_data` を有効にしてある

## テスト

```sh
godot --headless --path . --import                       # 初回のみ（クラス名キャッシュの生成）
godot --headless --path . --script tests/run_tests.gd    # 所作の判定・女房の規則・全陳情が解けること・画面の流れ
```

見た目の確認は `tools/screenshot.gd`（画面のある環境で `SHOT_DIR=保存先 godot --path . --resolution 720x1280 --script tools/screenshot.gd`）。

## 構成

| パス | 内容 |
|---|---|
| `scripts/core/gesture.gd` | 扇の開閉の時刻から所作と特徴を読み取る（UI に依存しない） |
| `scripts/core/interpreter.gd` | 女房の規則の照合と、結果の5分類（UI に依存しない） |
| `scripts/core/game_data.gd` | JSON の読み込みと検証、文言の差し込み（自動読み込み `GameData`） |
| `scripts/core/fan_input.gd` | 扇の入力（自動読み込み `Fan`） |
| `scripts/ui/main.gd` | 画面と流れ |
| `scripts/ui/stage_view.gd` | 御簾・御方の影・扇・香の仮の絵 |
| `scripts/ui/ui_theme.gd` | 配色とフォント |
