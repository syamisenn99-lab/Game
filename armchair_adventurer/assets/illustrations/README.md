# イラストの置き場所

ここに絵のファイルを置くと、ゲームが**名前で見つけて自動で表示**する。絵が無い場所は、何も表示されない（ゲームは普通に遊べる）。

いまある絵は、`tools/make_placeholder_art.py` で作った**仮の絵**（子供が描いたようなヘタウマ風のSVG）。本物の絵ができたら、**同じ名前の `.png` を置く**だけで、仮の絵より優先して表示される。

## フォルダと名前

| フォルダ | 用途 | 大きさの目安 | 名前 |
|---|---|---|---|
| `sketches/` | 冒険者のスケッチ（通信ログに、文字送りが終わると出る） | 横400 × 縦300（4:3） | 下の表の「絵の名前」 |
| `sketches/<冒険者id>/` | その冒険者だけが描く版（あれば優先される） | 同上 | 同じ名前 |
| `portraits/` | キャラの顔（準備画面、探索画面のヘッダー） | 256 × 256 | `childhood`、`mercenary`、`doctor`、`noble`、`sister`（姉。ノベル場面で使う） |
| `backgrounds/` | ノベル場面の背景（あれば表示される） | 1280 × 720 | 場面の名前（下の表） |

- 冒険者id: 幼なじみ = `childhood`、傭兵 = `mercenary`、医師 = `doctor`、没落貴族 = `noble`
- 形式は **PNG**（背景は透明）が基本。`.webp` `.jpg` `.svg` も読める。同じ名前があれば、`png → webp → jpg → svg` の順に使う。
- ファイルを置いてGodotでプロジェクトを開くと、自動で取り込まれる。

## スケッチの名前と、使われる場面

| 絵の名前 | 使われるイベント |
|---|---|
| `mushroom` | 幼なじみ・医師: 青い斑点のキノコ |
| `beast` | 幼なじみ: 爪の獣（2回）／傭兵: 獣 |
| `statue` | 幼なじみ・傭兵・貴族: 目が光る石像 |
| `moss` | 幼なじみ・医師: 光る苔 |
| `pit` | 幼なじみ: 色の濃い床（落とし穴の目印） |
| `pit_deep` | 幼なじみ: 底が見えない落とし穴 |
| `bat` | 傭兵・医師: コウモリ |
| `pattern` | 傭兵・貴族: 壁と床の幾何学模様 |
| `tablet` | 傭兵・貴族: 古い石板 |
| `herb` | 医師: 月影草（銀色の葉脈の草） |
| `keyhole` | 貴族: 石の扉の星形の鍵穴 |

冒険者ごとの絵柄（傭兵＝雑、医師＝きれいな線と書き込み、貴族＝装飾的）の仮の絵は、`sketches/<冒険者id>/` に入っている。たとえば `sketches/mercenary/beast.png` を置けば、傭兵の獣の絵だけが置き換わる。専用の絵が無い冒険者は、`sketches/beast.png`（共通の絵）を使う。

## 新しい絵を使うイベントを足すとき
`scripts/data/sample_data.gd` の `SKETCHES` に「イベントid → 絵の名前」を1行足し、同じ名前のファイルを `sketches/` に置く。

## 権利について
自分で描いた絵のほか、画像生成ツールなどの出力を使うときは、**商用利用の可否**をツールの規約で確認すること。

## ノベル場面の背景
`backgrounds/<場面id>.png` を置くと、その場面の背景に出る（文章枠の後ろ）。場面idは次のとおり。

| 場面id | 場面 |
|---|---|
| `prologue` | プロローグ |
| `intro_childhood` `intro_mercenary` `intro_doctor` `intro_noble` | 冒険者の紹介 |
| `clue_1` 〜 `clue_5` | 姉の手がかり |
