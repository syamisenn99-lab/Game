# 安楽椅子冒険者（仮題） ゲームデザインドキュメント

> 状態: 企画メモの整理版 v0.1 / エンジン: Godot Engine / 開発者: 初めてのゲーム開発
> 本書は元メモを「確定した核」「拡張案」「未決事項」に分けて整理したもの。

---

## 1. 一言で言うと

家から出られない主人公が、耳飾り型の遺物で冒険者と「声だけ」でつながり、手元のノートと照合しながらダンジョン探索をナビゲートする、情報照合サスペンス。
『Papers, Please』の「机の上の書類仕事の緊張感」を中世ファンタジーに移し、そこに**冒険者たちとの関係性（町の一員としての日常）**を重ねる。

- ジャンル: リアルタイム・シミュレーション / 情報照合サスペンス / 会話・関係性ドラマ
- 最終目標: 消息不明の姉を探し、失踪の真実を解明する
- 途中目標: 生活費を切らさず、ガイド報酬で資金を得る（あるいは遺物を使う）

## 2. 世界観

- 中世程度の技術水準の世界。巨大な地下遺跡「ダンジョン」が発見された。
- 内部には未知の植物・生物（生活資源）と、超常的な道具「遺物」がある。
- それらを持ち帰って生計を立てる人々が「冒険者」と呼ばれる。
- ダンジョン情報は公的には出回っておらず、情報そのものが価値を持つ。
- **町の雰囲気**: 英雄の物語ではなく「普通の町」。冒険者は町の一員。英雄は別にいて、ときどき遭遇する存在。町には町の危機もある。

## 3. 主人公と物語の骨格

1. 主人公は体質的に自宅から出られない。両親は亡く、冒険者の姉と二人暮らしだった。
2. 姉は遺物「道連れの耳飾り」（付けた者同士の“声だけ”が遠距離で聞こえる）を主人公に贈り、冒険中もダンジョンの様子を語り続けた。主人公はそれを紙に書き留めていた（→ ノートの原型）。
3. ある日、姉が深層に潜った際に通信が途絶。役人が遺品として、姉が付けていた「道連れの耳飾り」（主人公の耳飾りと対）を届ける。
4. 引きこもっていた主人公のもとへ、冒険者になった幼馴染が訪れ、浅い階層のガイドを頼む。
5. 探索後、幼馴染が提案する。「耳飾りを貸し出してガイド業にし、姉の情報を集めよう」。
6. 主人公はガイド業を始め、冒険者たちと関わりながら姉を探す。

> 決定: 姉の遺品も主人公と同じ「耳飾り」に統一（元メモの「首飾り」は耳飾りに変更）。
> 「届いた耳飾り」を主人公自身が使えるかどうかは、後半の伏線として別途検討（§12）。

## 4. ゲームループ

```
【準備フェーズ】ノート整理 / ダンジョン情報の購入 / 次の探索者の選定
        ↓
【探索フェーズ】リアルタイム報告 ↔ ノート照合・指示（制限時間あり）
        ↓
【帰還・精算】報酬（資源・遺物）の獲得 / 姉の手がかり入手 / 会話・食事等のイベント
        ↓（準備フェーズへ）
```

## 5. コアメカニクス

### 5.1 通信
- 冒険者の「声」だけがテキストで届く。環境音・映像は無い。
- 報告は断片的で、冒険者ごとに「クセ」がある（§7）。

### 5.2 ノート（主人公の本）
- 姉から聞いた情報を記録したもの：リソース、アイテム、敵、罠など。
- **又聞きなので不完全・一部誤りの可能性あり**。冒険者の報告で更新・追記・整理して育てる。

### 5.3 照合（操作）
**A. ドラッグ＆ドロップ照合**
- 通信テキスト中のハイライト語（例「赤い斑点のキノコ」）を掴み、ノートの該当ページ（例「毒キノコの見分け方」）へドロップ。
- 正解なら主人公が自動で警告（「待って、それは毒だ！」）。

**B. 虫食い穴埋め**
- ノートに空白がある：「第2層の鋭い爪の獣は [ ？？？ ] を極端に嫌うらしい」
- 報告（「松明を近づけたら逃げた！」）を受け、「火」のキーワードスタンプを押して確定。
- 実装は「特定の空白に特定の単語アイテムをセットする」だけのフラグ管理でよい。

**C. 制限時間**
- 敵の接近、ダンジョン内の出来事が時間制限になる。
- 砂時計・時計の品質で指示までの猶予が延びる。

### 5.4 指示 × ダイス判定
- 能力値は4つ: **戦闘 / 観察 / 知識 / 精神**
- プレイヤーの指示が冒険者の判定の**目標値**を変える。
  - 正しい照合・指示 → 目標値が下がる（成功しやすい）
  - 読み間違い・誤指示 → 目標値が上がる（大失敗・罠発動のリスク）
- 判定: 冒険者の能力値 + ダイス目 ≥ 目標値で成功。
- 例: 「不気味な石像」報告 → ノートから「観察で隠しスイッチを探せば安全に止まる罠」と特定 → 「観察」を指示。

### 5.5 資金（経済）
| 収入 | 支出 |
|---|---|
| 冒険者から戦利品の一部を報酬として受け取る | 毎ターンの生活費 |
| | 冒険者・情報屋からの情報購入 |
| | 深い階層の探索許可 |
| | 強化アイテム（上質な砂時計/時計＝制限時間延長、高品質インクと付箋＝視認性向上・同時照合量増加） |

## 6. UI / ビジュアル方針

- 机の上に書類・ノート・付箋が並ぶ『Papers, Please』風の緊張感ある UI。
- **見やすさ最優先**。重要語のハイライト、情報量の多い場面でも視線誘導が崩れない配置にする。
- 冒険者が描くイラスト（探索メモ・モンスターのスケッチ等）は、**普段優秀な人ほど子供のような絵**にする。下手さがキャラの魅力とヒントの曖昧さ（＝照合の難しさ）になる。
- 口伝（声）と絵の両方から情報を探る。

## 7. 冒険者キャラクター（4〜5人）

| # | キャラ | 型 | 目的 | 報告のクセ | 攻略上の意味 |
|---|---|---|---|---|---|
| 1 | 幼馴染の少女 | 標準 | 主人公に元気になってほしい／姉を救いたい | 平均的 | チュートリアル役。関係性の軸 |
| 2 | ドライな傭兵 | 戦闘特化 | 莫大な金で自由（早期リタイア）を買い戻す | 事務的・コスト重視。単語照合は容易 | 遺物・魔法的現象への関心が薄く手がかりを見落とす |
| 3 | 訳ありの医師 | 探索・知識 | 未知の薬効成分の採取 | 生理変化・生態に詳細。パニックになりやすい | 早急な退避/解毒指示が必須 |
| 4 | 求道者の格闘家（保留） | 特殊踏破 | 肉体のみで極限環境を突破。金に無関心 | 筋肉・重さ・触覚ベースの感覚的報告 | 崖・足場など特殊地形を突破できる |
| 5 | 遺物狂いの没落貴族 | 解読 | 古代文明の真理。姉の遺物の秘密に最も近い | 長文・専門用語過多 | 長文から「必要なキーワード」を抜く読解力が要る |
| 6 | 故郷を支える運び屋（保留） | インベントリ管理 | 家族への仕送りのため売れる物を持ち帰る | 重量と価値の取捨選択を相談してくる | 市場価値×重量で最適な持ち帰りを指示 |

決定: 冒険者は**4人＝幼馴染・傭兵・医師・貴族**。格闘家と運び屋は「保留」（追加キャラ・後日拡張の候補）。MVPは幼馴染＋傭兵の2人から（§10）。

**4人の役割バランス（確認用）**
| キャラ | 照合で試される力 | 得意な能力値の傾向（案） | 苦手（案） |
|---|---|---|---|
| 幼馴染 | 基本の照合 | 全体的に平均 | 突出なし |
| 傭兵 | 単語照合は容易、見落としに気づけるか | 戦闘 | 知識（遺物への関心が薄い） |
| 医師 | 生理・生態の描写を毒/薬の項目に結びつける。パニック前に指示 | 観察・知識 | 戦闘・精神 |
| 貴族 | 長文から必要語を抜く読解力 | 知識 | 戦闘・体力 |

> 気づき: 能力値「精神」は、医師と貴族が苦手で傭兵が得意な構図になる。幼馴染は平均寄り。精神を軸にした場面（パニック・長時間探索）の見せ場を誰に持たせるかは要設計。

## 8. 関係性・日常システム（拡張案）

元メモ後半のアイデアを整理。**ここが本作の独自性になる一方、実装量が大きいので段階導入が前提。**

### 8.1 好感度
- **非表示**。選択肢の結果は複数キャラへ同時に作用する。
- 「普通と違う答え」が刺さるキャラがいる。見抜きやすい/見抜きにくいキャラを混在させる。
- 好感度でイベント進行が分岐。コミュニケーションエラー（すれ違い・誤解）も起こる。
- 同時会話は最大5人、4・3・2人の会話構成を想定。

### 8.2 性格類型の例
- **内向型**: 表情に出ない。干渉すると下がり、放っておくと上がる。単独行動の方が強い。
- 率直な物言いを好むエルフ、現代的な武器を使う魔族、潔癖なサキュバス、人に頼るのが苦手な姉肌のキャラ など。

### 8.3 世界設定の案
- 各種族の「あぶれ者」が魔界（ダンジョン）へ送り出されているというルール。
- 主人公は人間。異種族混成パーティも可。

### 8.4 シーン種別
- 食事 / 冒険中 / 野営 / 町の日常 / 町の危機 / 英雄とのエンカウント

### 8.5 周回要素・エンディング
- 隠れた好感度・選択肢の分岐が少しずつ分かる**周回アイテム**（ゲーム内完結）。
- エンディング案:
  - ダンジョンの真相が分かる終わり方
  - 一人になる終わり／一部のキャラがいない終わり
  - **全員が救われる終わり**（厳しい条件・1つだけ）

## 9. テーマ・トーンの指針

元メモの価値観メモを、シナリオ・選択肢設計の方針として整理。

- 「やられたらやり返す」を美徳にしない。傷つけた相手を傷つけても自分は嬉しくない、という感覚を物語の芯にする。
- 恥と罪悪感、「どうして私が気にしなきゃいけない」「嫌なら言えばいい」といった**言い分のぶつかり合い**を描く。
- 「こうあらねばならない」と他者から指定されるストレスを扱う。
- 「こんなこと言ったら嫌かな」と躊躇できる臆病さを肯定的に描く。
- 「なれなくていい、受け入れなくてもいい」――選択を迫りすぎない。
- 自分を妬む家族を助けるための依頼、といった**割り切れない依頼**を用意する。

> **注意（扱い方）**: 「自殺をほのめかす別れ」を入れる場合は、事前の内容警告、描写の抑制（方法を描かない）、支援窓口への導線などを設計時に検討すること。ゲーム表現のガイドライン（例: 自殺報道・表現に関するWHOの指針の考え方）に沿うと安全。

## 10. 開発方針（初めてのゲーム開発向け）

エンジンは Godot（2D UI に強く軽量）。**スコープを絞って「1本完走」を最優先**にする。

### MVP（まず作る範囲）
1. ノート画面（ページ切替・虫食い穴）
2. 通信ログ画面（ハイライト語のドラッグ＆ドロップ）
3. 照合 → 正否判定 → 目標値補正 → ダイス判定
4. 制限時間タイマー
5. 冒険者2人（幼馴染＋傭兵 or 医師）、探索1ダンジョン（2〜3層）
6. 精算・生活費のみの簡易経済

### 段階的に足すもの
| 段階 | 内容 |
|---|---|
| v0.2 | 冒険者を4人（医師・貴族を追加）に、ノート更新の永続化（セーブ） |
| v0.3 | 好感度（非表示）と会話イベント、食事・野営シーン |
| v0.4 | 町パート、強化アイテム、情報購入 |
| v0.5 | エンディング分岐、周回アイテム |

### 方針メモ
- 定期的に新要素を足してゲーム性が薄まらないか確認する（飽きの防止）。
- **もうゲームじゃなくなった部分は削る**。ただの読み物になっている要素は優先度を下げる。
- データ駆動（冒険者・アイテム・ノート項目を JSON/Resource で定義）にしておくと後から増やしやすい。

## 11. 実装メモ（Godot）

- 照合: `Control` の drag & drop（`_get_drag_data` / `_can_drop_data` / `_drop_data`）で実装できる。
- ノート項目: `{id, text_with_blanks, answer_keyword, state}` のような Resource にして、`state` で確定/未確定を管理。
- 判定: `target = base - bonus(指示の正誤)`、`roll = d20 + stat` のようなシンプル式から始める。
- 好感度: キャラごとの隠し変数＋選択肢タグの重み表。デバッグ用に可視化トグルを作る。

## 12. 決定事項と未決事項

### 決定済み
| 項目 | 決定内容 |
|---|---|
| 冒険者 | 最終4人: 幼馴染・傭兵・医師・貴族（格闘家・運び屋は保留。MVPは幼馴染＋傭兵） |
| 遺物の関係 | 姉の遺品も「耳飾り」に統一 |
| 姉の失踪の真相 | **自分の意思でダンジョンに残った**（事故・事件ではない） |
| 姉が残った理由 | **主人公の体質（家から出られない原因）を解く鍵がダンジョンにあり、それを得るため／解くために残った**（利他的動機） |
| ダンジョンの起源と体質 | ダンジョンは古代文明が作った「器（制御装置）」。主人公は**その適格者**で、外に出ると装置との同調が乱れて体調を崩す体質（案） |
| 「器」の正体 | **怒りや恥（やり返したい感情）を吸い取って閉じ込める古代の装置**。資源・遺物・魔物は閉じ込められた感情の副産物（案） |
| テンポ配分 | 探索中は照合に集中。会話・好感度イベントは準備／帰還フェーズに寄せる |

> 「真相＝姉の意思」の含意: 主人公は「救出」ではなく「姉の選択を知り、どう受け止めるか」に向かう。
> 「なれなくていい・受け入れなくてもいい」というテーマと整合し、
> 「全員救われる」エンディング（姉を連れ戻さずに救う道）や「一人になる」エンディング（姉の選択を拒む道）の両方を作りやすい。

#### 姉の動機の設計メモ
- 体質・耳飾り・ガイド業が一本の線でつながる（体質の原因＝ダンジョンの真相、の可能性）。
- **負い目の扱いに注意**: 「あなたのために残った」だけだと主人公に負い目を背負わせる。テーマ（§9）に沿って、
  - 姉は主人公に相談せず一人で決めた（主人公には「頼んでない」と思う権利がある）。
  - 主人公は姉の選択を**感謝しなくていい・受け入れなくてもいい**。怒り・拒絶・受容のどれも選べる。
  - 姉の動機が「正しい」かどうかは物語で断定しない。エンディングごとに答えを変える。
- 周囲（幼馴染・冒険者）が「姉のために」を主人公に押し付ける場面は、あえてすれ違いイベントにできる。

#### 起源設定の設計メモ（案）
- 「器」が何を封じ／保つ装置なのかは未定。冒険者が見つける資源・遺物は、その装置の副産物と解釈できる。
- 主人公の耳飾りは、通信道具であると同時に**主人公を「器」の端末につなぐ道具**だった、という真相が置ける。姉の耳飾りも対。
- 姉が残る理由は「主人公の代わりに制御を担う／同調を安定させる方法を探す」など、利他的動機とつなげやすい。
- 貴族（古代文明の真理を追う）と姉は、同じ謎に別々のルートから近づいていた、という関係にできる。
- ダンジョン情報が公的に出回らないのは、「器」の存在を権力側が把握・秘匿しているため、という理由付けも可能。
- 結末の幅: 体質が解ける／解けないまま折り合う／装置を止める、など。解けない結末を「失敗」にしない（§9）。

#### 「器」の設計メモ（案）
- 古代人は「やり返す感情」の連鎖で滅びかけ、感情を器に閉じ込めて争いを止めた。その代償として、器の維持には**感情と同調できる人間**が要る。
- 主人公は同調しやすい体質。外に出て人の感情に触れると同調が乱れ、体調を崩す。→「家から出られない」の理由になる。
- 報告で語られる冒険者たちの感情（傭兵の焦り、医師の罪悪感、貴族の没落の恥など）が、ダンジョン内の現象や魔物の姿に影響する、という演出が可能。照合ゲームに「感情が環境を変える」ルールが足せる。
- **扱いの注意**: 感情を「捨てていい悪いもの」として描かない。閉じ込めたことで争いは止まったが、悲しみや怒りの正当な居場所も消えた、という両面を残す。
- 結末の例:
  - 器を止める: 感情が戻る。やり返しの連鎖が再発するリスクと、感情が戻る救いの両方を描く。
  - 器を維持する: 誰かが同調役を担う。姉の選択をどう扱うかと直結。
  - 同調役を分担する／仕組みを変える: 「全員救われる」エンディング候補（厳しい条件）。
  - 正解を決めず、主人公が選ばないまま日常に戻る終わりも許容する（§9）。

### 未決
1. 古代人が感情を閉じ込めるまでの経緯（誰が器を作り、誰が代償を負ったか）。体質は解けるのか、解けないのか。
2. 届いた姉の耳飾りを主人公が使えるか。使えるなら、いつ何が聞こえるか。
3. 「精神」能力値の見せ場を誰に持たせるか。
   （付記: 姉が主人公に黙って決めた理由。通信を断った理由は事故か、意図的か。）
4. 好感度システムの規模（最初から4人同時か、2人から始めるか）。
5. 「英雄」「町の危機」を本編進行にどう絡めるか。
6. 周回アイテムの具体案（例: 「好感度の傾向が分かる手帳」）。
